# Redis 未授权访问实验命令记录
# 实验环境：Vulhub + Docker Desktop
# 操作系统：Windows 11
# 漏洞类型：Redis Unauthorized Access

==================================================
1. 下载 Vulhub
==================================================

cd /d E:\
git clone --depth 1 https://github.com/vulhub/vulhub.git

作用：
下载 Vulhub 漏洞环境集合。

--------------------------------------------------

==================================================
2. 进入 Redis 未授权访问目录
==================================================

cd /d E:\vulhub\redis\4-unacc

作用：
进入 Redis 未授权访问漏洞环境目录。

如果目录不存在，可以执行：

dir E:\vulhub\redis

查看 redis 目录下的具体漏洞环境名称。

--------------------------------------------------

==================================================
3. 启动漏洞环境
==================================================

docker compose up -d

作用：
使用 Docker Compose 启动 Redis 未授权访问漏洞环境。

--------------------------------------------------

==================================================
4. 查看容器运行状态
==================================================

docker ps

作用：
查看 Redis 容器是否正常运行，以及 6379 端口是否映射成功。

重点观察：

0.0.0.0:6379->6379/tcp

或类似端口映射信息。

--------------------------------------------------

==================================================
5. 使用本机 redis-cli 连接 Redis
==================================================

redis-cli -h 127.0.0.1 -p 6379

作用：
连接本地 6379 端口上的 Redis 服务。

如果可以直接进入 Redis 命令行，说明连接成功。

--------------------------------------------------

==================================================
6. 使用容器内 redis-cli 连接 Redis
==================================================

先查看容器名：

docker ps

然后执行：

docker exec -it 容器名 redis-cli

示例：

docker exec -it redis-4-unacc-redis-1 redis-cli

作用：
如果 Windows 本机没有 redis-cli，可以进入容器内部使用 redis-cli。

--------------------------------------------------

==================================================
7. PING 测试
==================================================

PING

预期结果：

PONG

作用：
测试 Redis 是否可以正常连接。

安全含义：
如果无需密码即可 PING 成功，说明 Redis 可以被未授权访问。

--------------------------------------------------

==================================================
8. INFO 查看 Redis 信息
==================================================

INFO

作用：
查看 Redis 服务器信息、版本信息、系统信息、连接信息等。

安全含义：
如果无需认证即可执行 INFO，说明 Redis 信息泄露风险较高。

--------------------------------------------------

==================================================
9. DBSIZE 查看 Key 数量
==================================================

DBSIZE

预期结果示例：

(integer) 0

作用：
查看当前数据库中 key 的数量。

--------------------------------------------------

==================================================
10. SET 写入测试数据
==================================================

SET testkey hello_vulhub

预期结果：

OK

作用：
写入测试 key。

安全含义：
如果无需认证即可写入数据，说明 Redis 存在未授权写入风险。

--------------------------------------------------

==================================================
11. GET 读取测试数据
==================================================

GET testkey

预期结果：

"hello_vulhub"

作用：
读取刚刚写入的测试数据。

安全含义：
如果无需认证即可读取数据，说明 Redis 存在未授权读取风险。

--------------------------------------------------

==================================================
12. 停止并清理环境
==================================================

docker compose down -v

作用：
停止 Redis 漏洞容器并清理数据卷。

--------------------------------------------------

==================================================
13. Redis 未授权访问成功条件
==================================================

Redis 未授权访问通常需要满足：

1. Redis 服务正在运行；
2. Redis 端口 6379 暴露；
3. Redis 没有设置认证密码；
4. 防火墙或安全组没有限制访问；
5. 客户端可以直接连接 Redis；
6. 无需 AUTH 即可执行命令。

--------------------------------------------------

==================================================
14. 防御方式
==================================================

常见防御方式：

1. 设置 Redis 访问密码；
2. 不将 Redis 暴露到公网；
3. 使用防火墙限制访问来源；
4. Redis 绑定到 127.0.0.1 或内网地址；
5. 关闭不必要的端口映射；
6. 重命名或禁用危险命令；
7. 监控 Redis 访问日志；
8. 定期扫描开放端口。

--------------------------------------------------
